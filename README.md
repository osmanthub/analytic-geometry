# 几何学基础—解析几何

面向大学本科的解析几何学习网站，包含向量与坐标、平面与空间直线、柱面锥面旋转曲面与二次曲面、二次曲线理论。

**学生入口：<https://osmanthub.github.io/analytic-geometry/>**

部署成功后，学生可直接用浏览器访问，不需要登录 ChatGPT 或 GitHub。资源在本站加载，公式、讲义阅读器、字体与交互程序不依赖外部 CDN。

## 学习内容

- 按知识点阅读课程讲义，核对概念、记号和难点。
- 调节曲面参数、空间视角、坐标与截平面，观察对应图形和交线。
- 按纸笔作图步骤学习标准曲面、曲面交线和空间区域。
- 使用 58 道精选习题：先读题，再分析和计算，最后查看完整解答与逻辑链。
- 使用 26 道曲面作图题、原稿核对图和分步图。

## 手机、平板和离线使用

1. 首次联网打开学生入口；微信内打不开时，复制链接到 Safari、Chrome 或设备自带浏览器。
2. 打开网站的“离线学习”页面，下载完整课程资源。
3. 等待网站完成资源校验并提示完整，再进行断网测试。下载未完成时，不能保证离线使用。
4. 学习记录保存在当前浏览器中；可以导出记录备份，并在另一设备导入。

本站与原 ChatGPT Sites 地址属于不同网站，旧站缓存和学习记录不会自动迁移。请在旧站导出学习记录，再在本站导入；完整课程资源需在本站重新下载。浏览器清理数据后，应重新下载课程并导入记录。

原始出处中的外部链接需要联网。南开讲义及三份竞赛整卷/答案册不随本公开仓库分发；相关网页题干、本站整理的解答和课程主讲义仍保留。资源处理说明见 [第三方来源与许可](THIRD_PARTY_NOTICES.md)。

## 网站维护

网站文件位于 `docs/`，GitHub Pages 的发布源为 `main` 分支的 `/docs`。`.nojekyll` 用于按原样发布静态文件。

每次修改网页、讲义或图片后，重新生成离线清单，然后执行已有检查：

```sh
python3 scripts/build-offline-manifest.py
python3 scripts/build-offline-manifest.py --check
node scripts/test-offline-worker.cjs
node scripts/test-study-backup.cjs
node scripts/test-touch-controls.cjs
```

提交并推送后，在仓库 Settings → Pages 或 Actions 查看发布状态。发布完成后，实查首页、讲义阅读器、习题和交互实验；已有完整离线缓存的学生可在“离线学习”中更新课程。

本仓库只包含公开网站、维护脚本与许可说明，不包含私人工作目录、认证信息、原站部署凭据和旧版 Git 历史。课程素材保留各自作者与原出处，本仓库没有对第三方教材、题干和插图授予统一开放许可。
